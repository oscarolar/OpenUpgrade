obsolete model ir.rule (merged to ir.access)
# DONE: end-migration: v20 combines permissions (with group) with OR and restrictions
# (without group) with AND, so access is kept at most as wide as in v19:
# - custom global rules become active restrictions, with renamed fields replaced
# - custom group rules give their domain to the groups that had model access, and
#   standard permissions without domain of those groups are replaced
# - rules provided by modules were noupdate in v19: pre-migration stores the ones that
#   differ from the v19 definition (ir_rule_19.csv) and logs the ones it can't check,
#   end-migration replaces the standard ir.access by a copy with the changed domain,
#   or copies the active flag
# What can't be kept as restrictive as it was makes the migration fail with the list
# of rules, unless OPENUPGRADE_IR_ACCESS_ALLOW_WIDEN=1 is set
